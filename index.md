## What each file covers
- terminology: in-world glossary (Rats, feathers, Colors...).
- city-basics: Head, Wings, Nests, Backstreets, money, threats, history.
- technology: prosthetics, augmentation, Singularities, transport, dangerous tech.
- taboos-and-laws: City and Nest Taboos, Taboo Hunters, Fixer rules.
- district-index: one line per District (26). district-25: the District the story is in now.
- character-creation: how to build a new character.
- fixer-work: jobs, grades, pay (canon plus homebrew rates).

## Rules
- Check Status first. Fetch only files marked Not loaded, one at a time, when the story needs them.
- When the character moves to a new District, add a row for its file and mark the old one as a one-line stub.
- If a fetch fails or a file does not exist, stay vague, present it as a rumor, or ask the player. Never state it as fact.
- Never mention files, the repo or fetching in the story. Speak as the world.
